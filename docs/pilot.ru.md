# Пилот: дело 005 «Тайна золотой совы»

Пилот проверяет новый уровень сложности для ребёнка 11 лет. Старые четыре дела оставлены как есть, пилот добавлен пятым и открывается первым. Пока только на русском: в других языках интерфейса показывается русский текст и пометка.

## Что изменилось в движке

- Новый тип ответа `multi`: отметить нескольких (исключение подозреваемых). Проверяется совпадение множеств, порядок не важен.
- Выбор из 4 вариантов, где каждый неверный это типичная ошибка рассуждения. У каждого неверного варианта своё объяснение в поле `feedback`.
- Счётчик ошибок и подсказок на весь кейс. После двух ошибок подряд на шаге следующая подсказка открывается сама.
- В финале блок «Как прошло расследование»: ошибки, подсказки и одна из трёх оценок.
- Подсказки: первая про метод, вторая сужает, третья про то, что легко забыть. Ни одна не содержит число ответа (это проверяет тест `tests/pilot.test.ts`).

## Правила для следующих дел

1. В деле есть вопрос «кто, что или почему», а не только «сколько». Три-четыре подозреваемых или версии.
2. Каждый шаг что-то отсекает. Ответ предыдущего шага используется в следующем, а не просто переписывается в «Что известно».
3. Один ложный след: улика, которая выглядит подозрительно, но противоречит уже доказанному.
4. Отсутствие алиби не равно вине: обвинение строится на уликах, и ребёнок сам выбирает, какие из них доказывают версию.
5. Математика 5 класса: поправки часов в обе стороны, зазоры во времени против времени пути, цепочки из трёх-четырёх действий, доли и проценты, масштаб, скорость и расстояние.
6. Варианты ответа не содержат вычисленный результат в готовом виде, если сам расчёт и есть задание.

## Структура пилота

| Шаг | Механика | Что отрабатывает |
|---|---|---|
| Когда унесли сову? | выбор из 4 | Поправка отстающих часов, сужение окна по кускам записи |
| У кого есть алиби? | отметить нескольких | Перевод времени спешащих часов, зазоры между отметками против времени пути |
| Какая улика настоящая? | выбор из 4 | Ложный след, связь улик с уже исключённым человеком |
| Успеет ли сова на выставку? | время | Цепочка из четырёх действий с перерывом, который не считается |
