# Оформление дел

Цвета принадлежат миру истории и не зависят от языка интерфейса. Декоративные акценты можно менять; значимые для загадки цвета (например, жёлтый и синий значки) остаются неизменными. Фон не содержит текста заданий. Задания размещаются на плотных панелях, чтобы иллюстрация не мешала чтению.

## Реализовано: пропавшая сова

В `app/themes.ts` находятся четыре сцены. Коридор - ночной синий и золото; двор - глубокий зелёный и светлый зелёный акцент; библиотека - чернильный и янтарный; развязка в театре - бордовый и золото. Фон и поверхности переключаются вместе с местом действия. В сцене сопоставления улик детектив остаётся в библиотеке.

Фоны созданы с помощью ImageGen специально для игры. Новые иллюстрации сохранены как WebP для уменьшения загрузки. Файл `scene.png` - исходный школьный коридор.

## Дела 005-011: временные фоны

Для этих дел иллюстраций пока нет. В игре стоят стилизованные SVG-сцены, которые генерирует `scripts/backgrounds.py` в палитрах ниже (`public/backgrounds/<id>-0..3.svg`). Когда появятся нарисованные фоны, достаточно положить четыре файла и поменять расширение в `storyScenes` в `app/themes.ts`. Промпт общий с лесным делом (`docs/forest-art.md`), сюжеты сцен по шагам:

| Дело | Сцены 0-3 |
|---|---|
| greenhouse | зал под куполом с рядами ростков; ряд с тележкой ящиков; коридор с нишами; пульт оранжереи |
| theatre | видеоархив; сцена с гирляндами и мостом; склад реквизита; стол режиссёра с планом |
| aquarium | аквариум с замком, лодкой, ракушкой и сундуком; пульт с четырьмя программами; журнал сундука; показ с кольцами пузырьков |
| bakery | прилавок с коробкой и тарелкой разбитых лун; журнал и фотографии; стол с тестом и весами; печь |
| lighthouse | игрушечный маяк ночью; экран с программой; карточка мелодии; маяк с огоньком над морем |
| library | полки с изданиями; читальный стол с двумя заметками; папка ремонта с копиями; комната клуба |

Музыка включена по умолчанию, тихо (18%). Если браузер запрещает автоматический звук, она запускается при первом касании или нажатии клавиши. Музыку можно выключить кнопкой. Она, повторяется и ставится на паузу при скрытии вкладки. На устройствах, ограничивающих изменение громкости HTML-аудио, уровень также регулируется системными кнопками.
