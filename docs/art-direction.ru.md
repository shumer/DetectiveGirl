# Оформление дел

Цвета принадлежат миру истории и не зависят от языка интерфейса. Декоративные акценты можно менять; значимые для загадки цвета (например, жёлтый и синий значки) остаются неизменными. Фон не содержит текста заданий. Задания размещаются на плотных панелях, чтобы иллюстрация не мешала чтению.

## Реализовано: пропавшая сова

В `app/themes.ts` находятся четыре сцены. Коридор - ночной синий и золото; двор - глубокий зелёный и светлый зелёный акцент; библиотека - чернильный и янтарный; развязка в театре - бордовый и золото. Фон и поверхности переключаются вместе с местом действия. В сцене сопоставления улик детектив остаётся в библиотеке.

Фоны созданы с помощью ImageGen специально для игры. Новые иллюстрации сохранены как WebP для уменьшения загрузки. Файл `scene.png` - исходный школьный коридор.

## Направления для десяти будущих дел

Эти дела пока существуют как сценарии. Ниже план палитр и иллюстраций для их реализации, а не уже доступные игровые экраны.

| Дело | Палитра | Фон |
|---|---|---|
| Тайна светящихся грибов | Хвойный зелёный, свет мха, янтарь | Сказочная тропа и бумажные грибы-фонари |
| Посылка для облачного острова | Небесный синий, белый, медь | Воздушная почта над облаками |
| Музей перепутанных теней | Индиго, сиреневый, свет проектора | Зал с силуэтами и проектором |
| Сигнал с лунной оранжереи | Космический синий, бирюза, зелёный | Стеклянный сад на Луне |
| Театр потерянного финала | Бордо, тёплое золото | Кукольная сцена и реквизит |
| Аквариум и загадка пузырьков | Морская синь, бирюза, коралл | Подводный дворец |
| Пекарня лунных пряников | Шоколадный, медовый, кремовый | Вечерняя пекарня, звёздные пряники |
| Маяк, который забыл мелодию | Ночной синий, белый, жёлтый | Музыкальный маяк и море |
| Библиотека невидимых закладок | Тёмный сливовый, дерево, янтарь | Полки, каталоги, лампа |
| Парк и пропавший маршрут парада | Зелёный, небесный, солнечный жёлтый | Парк, фонтан и маленькие роботы |

Музыка запускается только по явному нажатию, тихо (18%), повторяется и ставится на паузу при скрытии вкладки. На устройствах, ограничивающих изменение громкости HTML-аудио, уровень также регулируется системными кнопками. Кредит и лицензия находятся в игре и `MUSIC-LICENSE.md`.
