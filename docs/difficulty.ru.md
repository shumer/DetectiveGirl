# Уровень сложности: 11 лет

Правила, по которым переписаны четыре игровых дела. Новые дела и переработка черновиков должны им следовать.

## Движок

- Типы ответа: `choice` (не меньше четырёх вариантов), `multi` (отметить нескольких, порядок не важен), `order` (карточки по порядку), `number`, `time`.
- У каждого неверного варианта `choice` есть своё объяснение в поле `feedback`: почему именно этот ход мысли не работает. У верного варианта пустая строка.
- Счётчик ошибок и подсказок на всё дело. После двух ошибок подряд на шаге следующая подсказка открывается сама. В финале блок «Как прошло расследование» с одной из трёх оценок.
- Подсказки: первая про метод, вторая сужает, третья про то, что легко забыть. Ни одна не содержит ответ. Для `number` и `time` это проверяет тест `tests/reviewed-content.test.ts`.

## Содержание

1. В деле есть вопрос «кто, что или почему», а не только «сколько». Три-четыре подозреваемых или версии.
2. Каждый шаг что-то отсекает. Ответ предыдущего шага используется в следующем, а не просто переписывается в «Что известно».
3. Один ложный след: улика, которая выглядит подозрительно, но противоречит уже доказанному (Лев с бумагой, незнакомец у поляны, вторая коробка на 1,6 кг, заявка Тимура).
4. Отсутствие алиби не равно вине: обвинение строится на уликах.
5. Математика 5 класса: поправки часов в обе стороны, зазоры во времени против времени пути, цепочки из трёх-четырёх действий, доли, масштаб, скорость и расстояние, время от нестандартной точки отсчёта.
6. Неверные варианты это типичные ошибки рассуждения (забыл поправку, применил её не в ту сторону, посчитал часть вместо целого), а не мусор.
7. Варианты не содержат готовый результат, если расчёт и есть задание.

## Что отрабатывает каждое дело

| Дело | Ключевые навыки |
|---|---|
| 001 Сова | поправка отстающих и спешащих часов, зазоры между отметками против времени пути, ложный след, цепочка с перерывом |
| 002 Фонари | накопительные суммы, проверка версии по времени, масштаб плана, доля от целого при зарядке |
| 003 Посылка | единицы массы, два признака вместо одного, скорость и расстояние, расписание с интервалом |
| 004 Музей | кратность, время от момента включения, порядок событий по относительным данным, очередь с длительностью |
